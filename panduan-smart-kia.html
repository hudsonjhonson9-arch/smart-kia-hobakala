1. Pengenalan Sistem

1.1 Apa itu SMART KIA?

SMART KIA adalah aplikasi web untuk mencatat dan memantau data kesehatan ibu dan bayi di Posyandu. Fitur utama:

  • Pencatatan data pasien (rekam medis)
  • Monitoring kunjungan ANC (Antenatal Care)
  • Pencatatan data persalinan
  • Monitoring masa nifas
  • Pencatatan data bayi baru lahir
  • Program Keluarga Berencana (KB)
  • Laporan dan grafik

1.2 Arsitektur Sistem

2. Login ke Sistem

Gambar 2.1 — Halaman Login SMART KIA

Cara Login

  1. Buka browser, ketik https://smart-kia-hobakala.vercel.app

4. Modul Pasien (RM)

Gambar 4.1 — Daftar Data Pasien

4.1 Menambah Pasien

  1. Klik "Pasien (RM)" di sidebar
  2. Klik "➕ Tambah"
  3. Isi formulir: No RM, Nama Ibu, Nama Suami, NIK, Umur, Alamat, No HP
  4. Klik "Simpan"

4.2 Edit / Hapus

Klik tombol "Edit" atau "Hapus" pada baris data yang diinginkan.

Peringatan: Penghapusan data bersifat permanen.

5. Modul ANC (Antenatal Care)

Gambar 5.1 — Formulir Data ANC

5.1 Cara Menambah Data ANC

  1. Klik "ANC" di sidebar
  2. Klik "➕ Tambah"
  3. Pilih No RM pasien
  4. Isi data: Tanggal Kunjungan, DJJ, UK, HB, Syphilis, HIV, HbSAg, GolDA, GDS, Keluhan, Rujuk
  5. Klik "Simpan"
Tips: Pastikan No RM sudah terdaftar di modul Pasien sebelum menambah data ANC.

6. Modul Persalinan

Gambar 6.1 — Formulir Data Persalinan

6.1 Cara Mengisi

  1. Klik "Persalinan" di sidebar
  2. Klik "➕ Tambah"
  3. Pilih No RM, isi: Tanggal Persalinan, Usia Kehamilan, Jenis Persalinan, Jenis Kelamin Bayi, Berat Bayi, Rujuk
  4. Klik "Simpan"

7. Modul Nifas

Gambar 7.1 — Formulir Data Nifas

  1. Klik "Nifas" di sidebar
  2. Klik "➕ Tambah"
  3. Pilih No RM, isi: Tanggal Kunjungan Nifas, Kunjungan Nifas Ke, Keadaan Umum, TFU, Lochia, ASI, Rujuk, Keterangan
  4. Klik "Simpan"

8. Modul Bayi

Gambar 8.1 — Formulir Data Bayi

  1. Klik "Bayi" di sidebar

14. Arsitektur & Deploy

14.1 Struktur File

smart-kia/
  ├── index.html — Frontend
  ├── code.gs — Backend Google Apps Script
  ├── screenshots/ — Screenshot panduan
  └── PANDUAN_SMART_KIA.pdf — Panduan PDF

14.2 Deploy ke Vercel

  1. Buka vercel.com, login dengan GitHub
  2. Klik "New Project" → pilih repo smart-kia-hobakala
  3. Klik "Deploy"
  4. Website tersedia di smart-kia-hobakala.vercel.app

14.3 Deploy ke Google Apps Script

  1. Buka script.google.com
  2. Buka project SMART KIA
  3. Deploy → New deployment → Web app
  4. Execute as: Me, Who has access: Anyone
  5. Salin URL Web App
Catatan: Setiap perubahan code.gs harus re-deploy di GAS.

15. Troubleshooting

MasalahSolusi
Login gagalHubungi admin untuk reset password
Loading lamaTunggu beberapa detik, GAS butuh warm-up
Data kosongPastikan sudah menambah data di modul terkait
Error 500Refresh halaman, cek log di Google Apps Script
Error koneksiPeriksa koneksi internet

Tips Performa

  • Gunakan Chrome atau Edge untuk performa terbaik
  • Bersihkan cache browser secara berkala
  • Gunakan WiFi untuk upload data banyak
